# خطة تطوير الصفحة الرئيسية والتصنيفات

## الواجهة العامة
- إبقاء الواجهة المميزة والهوية الحالية، مع حذف صف الحلقات من الصفحة الرئيسية فقط.
- إضافة شريط أفقي متجاوب: جميع المسلسلات، العربية، الأجنبية، التصنيفات، مجموعة خاصة.
- عرض «أُضيف حديثاً» مرتباً حتى تاريخ الإضافة، ثم «المسلسلات القديمة» لبقية المسلسلات، باستخدام شبكات البوسترات العمودية الحالية.
- عند اختيار العربية أو الأجنبية أو مجموعة خاصة، إظهار المسلسلات المرتبطة بالتصنيف المقابل فقط. وعند فتح التصنيفات، إظهار أزرار التصنيفات ثم نتائج التصنيف المختار.
- عدم تعديل صفحات المسلسل أو الحلقة أو البحث أو روابط الفيديو.

## إدارة التصنيفات فقط
- إضافة تبويب «التصنيفات» إلى لوحة الإدارة.
- السماح بإضافة تصنيف جديد وتعديله وحذفه، مع أسماء اللغات الأربع ورابط مختصر تلقائي.
- الاستفادة من اختيار التصنيفات الموجود أصلًا في نموذج المسلسل، دون تعديل بقية لوحة الإدارة.

## البيانات والتحقق
- استخدام جدولي `genres` و`series_genres` الحاليين؛ لا migration ولا بيانات تجريبية ولا حذف محتوى.
- إضافة اختبارات لترتيب الحديث/القديم والتصفية وإضافة تصنيف.
- تشغيل الاختبارات وفحص الواجهة على الهاتف والكمبيوتر، ثم مراجعة سجل البناء وحفظ التغييرات في Git.
